# Background Papers

## Chest X-ray Analysis with Large Vision-Language Models

1. **CheXpert: A Large Chest Radiograph Dataset with Uncertainty Labels**
   Irvin et al., AAAI 2019. CheXpert taxonomy used for ground-truth labels in MIMIC-CXR.

2. **MIMIC-CXR-JPG: A Large Publicly Available Database of Labeled Chest Radiographs**
   Johnson et al., 2019. Dataset used for validation in this project.

3. **GPT-4 Technical Report** — OpenAI, 2023.
   Demonstrates multimodal (vision) capabilities used for X-ray analysis.

4. **Visual Grounding in Medical Imaging: A Survey**
   Covers bounding-box localization approaches for radiology report generation.

5. **ChatClinic: A Multi-Modal Clinical Chat Platform**
   bispl-create/chatclinic-multimodal. Plugin framework this tool integrates with.
